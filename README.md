# 本地化工具

基于 .NET 8 / WPF UI 的本地化编辑和翻译工具，统一使用 `.locproj` 项目工作副本。

## 日常流程

1. 点击「新建项目」，选择游戏使用的正式语言目录（可以是空目录），确认语言文件命名规则、文件格式和源语言，再选择 `.locproj` 的保存位置。创建时只读取规则中匹配的语言文件，不修改正式目录。
2. 在「新增」页填写或粘贴以 Tab 分隔的 Key / 文本，点击「加入项目」。内容立即进入项目源语言，无需拷贝文件。
3. 在「翻译」页选择目标语言和翻译方式。结果保存到项目工作副本，可直接到「编辑」页检查、修改并保存。
4. 点击「导出游戏资源」核对各语言的新增、修改、删除，再点击「备份并发布」写回正式目录。
5. 下次启动会重新打开上次项目，也可以通过「打开项目」切换。

任务执行窗口会显示当前翻译步骤和运行时长，可随时安全取消。设置页「应用外观」支持跟随 Windows、浅色和深色模式；主窗口与任务窗口共用主题和标题栏标识。

不再提供旧目录模式或迁移入口。程序不会清理已有的旧目录或文件。

## 合并别人改过的 JSON

导出的 JSON 交给别人后，对方可以直接修改、新增或删除文案（例如在 Unity 工程里手改或用 AI 批量处理）。收到文件后无需重新建项目：

1. 打开原项目，把 JSON 文件或整个语言目录拖进窗口，或点击「导入 JSON 修改」。文件按文件名或 ISO 代码识别语言，识别不了时会询问。
2. 程序从项目的版本记录中找出这份文件最可能基于的版本（导出过的、收到过的或创建项目时的文件）作为基准，在预览顶部显示，然后逐条比较「基准 / 当前项目 / 传入文件」：
   - 只有对方改了：自动采用对方的内容；只有项目里改了：保留项目内容；双方改成相同内容：跳过。
   - 双方改成不同内容，或一方删除、另一方修改：列为冲突，可选择保留当前、采用传入或手动编辑。
   - 对方删除且项目里没动过的 Key 会明确列为「删除」。文件只包含部分 Key 时，不会把缺少的 Key 当作删除。
   - 找不到对应版本时（例如文件来自其他项目），新增仍可直接合并，内容不同的已有文案需要逐条确认，不推断删除。
3. 冲突没处理完可以「保存进度，稍后处理」；合并后可在「项目 → 撤销上次合并」恢复。源文被修改时，已有译文保留并标记为待重译。

同一份文件重复拖入不会再产生变化；对方在上次文件基础上继续修改后再次发来，只会显示新的改动。

## 保存与发布

- 「保存 / 加入项目」只更新 `.locproj`，不会直接修改游戏文件。项目里已保存但未发布的更改，关闭程序后仍保留；尚未保存的表格编辑会询问如何处理。
- 源语言、语言映射和转换器随项目保存。项目打开期间不能在设置页切换这些配置；新建项目时可以重新选择。
- 自动翻译只处理新增、缺少译文、译文为空或手动标记为待重译的条目，其他已有译文始终保留。
- 产品发现旧词条有问题时，可在编辑页选中 Key 并「标记重译」，选择一种或全部目标语言。新增/缺失 Key 与手动标记的旧 Key 可以在同一次翻译中处理；旧译文会一直保留到对应语言的新结果通过完整校验并成功应用。失败或取消时标记不丢失，也可以用同一入口取消标记。
- 翻译结果会校验 Key 集合、空译文及常见占位符 / 标签（如 `{0}`、`%s`、`<b>`）。源文或译文在请求期间发生变化时，不应用过期结果。仍建议发布前人工检查译文。
- 编辑页「删除选中 Key」会从项目的所有语言中删除该 Key，发布时才影响正式文件。「撤销更改」只恢复当前表格到最近一次保存 / 加载状态，不撤销已经保存的项目操作。
- 发布只写入内容发生变化的语言文件，不创建从未翻译过的空语言文件，也不处理映射规则之外的文件。
- 发布前会核对正式文件是否被外部修改；发现变化就阻止覆盖。可通过「项目 → 高级操作 → 同步游戏资源中的外部修改」把正式目录中的变化合并进项目后再导出。
- 每次发布先把原文件按原始字节备份到 `<项目文件>.backups`。写入发生异常时尝试回滚；若外部并发修改使回滚无法安全完成，会保留备份并报告具体文件。断电等进程外中断不保证自动回滚。
- 「项目 → 高级操作 → 恢复上次发布」将正式文件恢复到上次发布前，保留当前工作副本为未发布状态。正式文件在发布后被外部修改时，会阻止恢复。更早的备份保留在备份目录，界面只支持恢复最近一次发布。

`.locproj` 包含各语言内容、基线和正式目录的绝对路径，不包含 API Key。它可以放在游戏目录之外；移动游戏目录后不会自动重定位。保管项目时请同时保留旁边的 `.backups` 目录和 `.history` 目录（合并前的项目副本，以及用于匹配合并基准的导出 / 收到的文件版本，每种语言保留最近 30 份）。`.locproj.lock` 是多实例写入锁文件，可留在原处。

## 环境与翻译方式

- Windows 和 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)。
- Google / DeepL / DeepSeek 网页翻译需要本机安装 Edge、Chrome 或 Firefox；API 翻译不需要浏览器。
- DeepL 网页翻译未登录时单次最多 1500 字符，程序会自动分批；语言规则中的 `zh-CN` / `zh-TW` 会自动换成 DeepL 的简体 / 繁体中文代码。DeepL 不支持的语言会在日志中报错。
- API 模式在设置页填写接口地址、Key、模型及提示词。设置保存于本机 `data/config.json`，请勿把该文件作为项目资料分享。
- 手动 AI 翻译不需要 API Key 或浏览器驱动，可使用任意 AI 对话服务，提示词与其他 AI 翻译方式共用。

### 手动 AI 翻译

1. 在「翻译方式」中选择「手动 AI（复制 / 粘贴）」，选好目标语言后点击「开始翻译」。
2. 在弹窗中点击「复制提示词」，粘贴到你使用的 AI 对话中发送。提示词包含本次待翻译的条目和目标语言，可在设置页修改通用 AI 提示词。
3. 复制 AI 的完整回复，粘贴或手动输入到弹窗的回复框，点击「校验并保存」。程序支持解析带说明文字、Markdown 代码块及 `[end]` 结尾的回复，并检查 Key、空译文、占位符及标签；校验失败会保留输入，可修正后再次提交。
4. 校验通过后保存到项目工作副本，可到编辑页检查后再发布。选择「全部目标语言」时逐个语言弹窗；取消或关闭弹窗会停止本次任务，已完成的语言仍保留，再次开始时只处理尚未完成的条目。

### 浏览器驱动

网页翻译通过 Selenium 工作。程序使用 Selenium Manager 下载与本机浏览器匹配的驱动，并缓存到数据目录的 `web-drivers`。

- 设置页「浏览器」默认为「自动」，优先选择本机 Edge，也可以手动指定。
- 网络受限时可填写「驱动代理」，例如 `http://127.0.0.1:7890`。
- 也可以把对应的 `msedgedriver.exe` / `chromedriver.exe` / `geckodriver.exe` 放入数据目录的 `web-drivers`，下载失败时会回退使用。

### 语言规则与转换器

数据目录 `iso` 中每个文本文件是一组语言规则，每行格式为 `文件名,ISO代码`，例如 `English,en` 对应正式目录中的 `English.json`。转换器实现 `IDictConverter` 接口，扩展 DLL 放在数据目录的 `converters`；接口由解决方案单独生成 `IDictConverter.dll`，发布包中会一起提供。

## 安装与更新

从 [GitHub Releases](https://github.com/rickytheoldtree/game-json-localization-wpf/releases) 下载 `Setup.exe` 安装，或下载 `Portable.zip` 解压使用。启动时会自动检查更新，也可以在「设置 → 更新与数据」手动检查；更新前会先处理未保存的表格编辑。

数据目录保存配置、`iso`、`converters` 和浏览器驱动，更新不会覆盖：

- 安装版：`%AppData%\LocalizationTranslationWPF`，卸载后仍保留。
- 便携版：解压目录下的 `data`。
- 直接运行编译输出（开发调试）：工作目录下的 `data`，不支持自动更新。

从旧的压缩包版本升级时，在「设置 → 更新与数据 → 旧版本数据」选择旧程序旁的 `data` 文件夹，重启后导入配置、ISO 和格式转换器。

## 构建与测试

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

该入口会依次检查代码格式、以“警告视为错误”构建整个解决方案，并运行数据与 WPF 界面回归；只需在无桌面的环境验证数据逻辑时可追加 `-SkipUi`。

## 发布新版本

发布通过 [Velopack](https://github.com/velopack/velopack) 打包并上传到 GitHub Releases，已安装的客户端会自动发现新版本：

```powershell
.\release.bat 1.2.0 release-notes.md
```

- 第一个参数是版本号（必须比上一版大），第二个参数是可选的 Markdown 更新说明，会显示在客户端的更新弹窗里。
- 需要先 `gh auth login`，或设置环境变量 `GITHUB_TOKEN`。打包工具 `vpk` 的版本固定在 `.config/dotnet-tools.json`，升级 Velopack NuGet 包时要同步修改。
- 脚本会下载上一版以生成增量包，打包完成后询问是否上传；选否时安装包留在 `release/velopack`，可以先本地试装。
- 产物包括 `LocalizationTranslationWPF-win-Setup.exe`（安装版，缺少 .NET 8 桌面运行时会自动安装）和 `LocalizationTranslationWPF-win-Portable.zip`（便携版）。

回归范围与隔离规则见 [测试说明](Tests/EditingRegression/README.md)。
