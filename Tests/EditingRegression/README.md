# 项目与编辑回归测试

无需额外测试框架的 .NET 8/WPF 控制台回归程序。任何断言失败都返回非零退出码。

在仓库根目录运行数据层测试：

```powershell
dotnet run --project Tests/EditingRegression/EditingRegression.csproj -c Release
```

在 Windows 交互式桌面上追加 WPF 控件测试：

```powershell
dotnet run --project Tests/EditingRegression/EditingRegression.csproj -c Release -- --ui
```

共 15 组数据层测试；加上 `--ui` 后共 16 组。UI 测试在屏幕外创建窗口并自动关闭，验证左侧导航默认页与设置入口、浅色/深色主题切换、带实时步骤和 Logo 的任务窗口、窄窗口折叠、取消离开时保留未保存页面、未打开项目状态、翻译范围切换、任务结束后恢复发布按钮、真实单元格编辑和校验、加入项目、删除后重新绑定、标记/取消旧 Key 重译、发布预览及通过真实按钮命令完成发布。它会导出浅色/深色项目页与任务窗口、欢迎页、新增页、最小窗口编辑页和发布预览的 PNG 截图。

所有测试都在测试程序输出目录的 `test-data/<随机 ID>` 中运行。不会读取或覆盖仓库中的 `data/config.json`、API Key 或用户语言文件。翻译使用模拟返回值，不打开外部浏览器，不调用付费 API。隔离目录和截图保留便于排查，路径在结束时输出。

## 覆盖范围

- 创建 / 打开项目、保存后重开；正式文件不受工作副本保存影响。
- 空 Key、重复 Key、与项目源语言冲突、修正与撤销。
- 排序 / 筛选、特殊字符搜索、隐藏行仍保存、空文本保留、批量粘贴通知合并。
- 编辑脏状态、取消编辑、恢复基线、解除旧数据表订阅、过期编辑快照保护。
- 新增内容直接用于翻译、已有译文保留、源文改变时需显式启用重译。
- 新增/缺失 Key 与手动标记的旧 Key 在同一任务中合并；重译标记按目标语言持久化，失败/取消时保留，成功后逐语言清除。
- AI 返回格式解析、Key / 占位符 / 空译文校验、过期结果保护、部分语言失败和取消。
- 发布差异、原始 UTF-16 / BOM 字节备份、恢复及删除本次发布新建的语言文件。
- 外部修改、过期 / 错项目预览、多实例项目文件冲突。
- 发布时项目文件写入失败，已写入的所有语言文件回滚；模拟失败仅将隔离项目文件临时设为只读。
- 恢复发布时拒绝覆盖外部修改。
- 路径穿越、重复文件名、无法解析的初始语言文件。

“撤销更改”是恢复整张表到保存/加载基线，不是逐操作的 Ctrl+Z，也不能恢复已经保存或跨语言永久删除的内容。
